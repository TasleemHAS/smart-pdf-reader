# Smart PDF Reader

A powerful ASP.NET Core web application that allows users to upload PDF files and ask questions about their content. The system extracts text from PDFs and provides intelligent answers based on the actual document content.

## 🚀 Features

- **PDF Upload & Management** - Upload and manage your PDF documents
- **Intelligent Q&A** - Ask questions about your PDF content
- **Real Text Extraction** - Extracts actual text from PDF files using PdfPig
- **Contextual Answers** - Provides answers with page references and context
- **Clean UI** - Modern, responsive Bootstrap interface
- **CRUD Operations** - Full create, read, update, delete functionality

## 🛠️ Technology Stack

- **Backend**: ASP.NET Core 6.0 MVC
- **Database**: Entity Framework Core with SQL Server
- **PDF Processing**: PdfPig for text extraction
- **Frontend**: Bootstrap 5, Font Awesome
- **Deployment**: Ready for Azure/Heroku deployment
